# my-skills

Personal skills. Each skill is a folder at the root of this repo.

## Start here

Read the entry skills in this order.

1. [cc-setup](cloudcanal-dev-test/skills/cc-setup/SKILL.md). Connect Mini, and link the skills onto this machine.
2. [pstack](pstack/README.md). On Cursor, use `/setup-pstack`. Codex sub-agent models are in [Codex agents](cloudcanal-dev-test/skills/cc-setup/SKILL.md#codex-agents). Do the work with `/poteto-mode`.
3. [cloudcanal-dev-test](cloudcanal-dev-test/SKILL.md). Develop on Air or Pro, and run tests and acceptance on Mini.
4. [cloudcanal-console-automation](cloudcanal-console-automation/SKILL.md). On a Console that is already signed in, manage datasources, operate jobs, and check results.
5. [datasource-lab](datasource-lab/SKILL.md). Use this for test databases, connections, and inspections on Mini.
6. [juantu-mode](juantu-mode/SKILL.md). Read this when the user asks you to work in Juantu's way. Codex and Cursor use the same file.

Each skill's own `skills/` folder holds the individual procedures. The entry skill takes you there with a path.
